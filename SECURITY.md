# Security reports and handling of sensitive material

This repository documents independent research. It is not a maintained camera firmware distribution, a vendor support channel, or a claim that Thinkware has acknowledged these findings.

For factual corrections that do not contain secrets, open a repository issue and identify the finding, firmware identity, test configuration, and the evidence that supports the correction. Do not post passwords, recordings, device serials, personal location information, private network addresses, or proprietary firmware bundles.

For a new product vulnerability, use the manufacturer's current official security-reporting channel. No specific response time or disclosure policy is promised by this repository. Publication dates and vendor contact, if any, will be recorded accurately in the README timeline.

Test only equipment and networks you own or are explicitly authorized to assess. Independent confirmation should preserve recordings and other owner data.
